# Project 03 – Online Learning Platform Interface

A sample e-learning interface featuring course categories, lesson previews, course descriptions, instructor profiles, learning objectives, progress indicators and enrolment-style links.

## Files
- `index.html` – semantic page structure and course content
- `styles.css` – responsive layout, course cards and visual styling

## Technologies
HTML5 and CSS3 only. No JavaScript is used.

## Note
This is a front-end demonstration. Course links and progress indicators are illustrative; there is no backend, account system or real enrolment.

## Run
Open `index.html` in a modern web browser.
