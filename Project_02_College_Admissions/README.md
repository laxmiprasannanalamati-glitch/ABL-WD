# Project 02 – College Information and Admissions Website

A college information interface with institutional overview, academic departments, admission steps, facilities, campus activities and contact information.

## Files
- `index.html` – page content and semantic HTML structure
- `styles.css` – page layout, cards, colors and responsive styling

## Technologies
HTML5 and CSS3 only. No JavaScript is used.

## Run
Open `index.html` in a modern browser. The official institution link is included for visitors to verify current admission details.
