How the Web Works

The internet connects computers and networks around the world. The web uses this infrastructure to share pages and information.

An IP address is a numerical address used to identify a device on a network. A browser requests a webpage from a web server using internet protocols.

HTML has developed through different versions. HTML5 introduced useful semantic elements and support for modern web content.
