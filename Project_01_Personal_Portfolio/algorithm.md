# Algorithm

1. START.
2. Open the portfolio webpage.
3. Display the home section and navigation.
4. Display about, skills and project sections.
5. When a navigation link is selected, move to that section.
6. When the menu button is selected on a small screen, show or hide the menu.
7. Accept contact details and validate required fields.
8. Display a confirmation message when the form is submitted.
9. STOP.
