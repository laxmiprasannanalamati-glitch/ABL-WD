What I Am Learning About Design

User interface: The visible parts of a website that people use.

User experience: How easy and comfortable a website is to use.

Visual design: Choosing suitable colors, readable typography and clear sections.

Accessibility: Adding meaningful image alternative text and clear link names.

Wireframe: A simple plan showing where the heading, menu, image and content will appear.

Prototype: An early model used to review a design before final development.

Design thinking: Understand the user's need, define the problem, think of ideas, create a simple wireframe and prototype, then improve the design.

Mobile-first design: Start with the most important content and keep the page structure simple for small screens.

My portfolio uses a simple page structure so visitors can find information easily.
