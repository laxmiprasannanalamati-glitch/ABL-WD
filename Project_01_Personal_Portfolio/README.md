# Project 01 — Personal Portfolio Website

A responsive student portfolio containing an introduction, about section, technical skills, sample projects and contact form.

## Files
- `index.html` — semantic page structure, sections, links, lists and form
- `styles.css` — colors, text styling, backgrounds, box model and responsive layout
- `script.js` — mobile navigation and contact form feedback

## Run
Open `index.html` in a web browser. The contact form is a front-end demo and does not send email.
