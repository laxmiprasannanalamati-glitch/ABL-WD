# Project 01 — Personal Portfolio Website

A responsive student portfolio containing an introduction, about section, skills, sample learning interests and contact information.

## Files
- `index.html` — page structure, headings, paragraphs, sections, lists, images and hyperlinks
- `styles.css` — colors, text styling, backgrounds, borders, spacing and page layout

## Technologies
HTML5 and CSS3 only. This project does not use JavaScript.

## Run
Open `index.html` in a web browser.
